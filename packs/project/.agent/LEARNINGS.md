# LEARNINGS

Read `docs/workflows/learning.md` for the authoritative modes and promotion policy.
Default OFF. This file contains records, not permission to edit instructions.

## Compass

Capture reusable evidenced lessons that change a future action. Avoid diaries,
one-off trivia, duplicates, and untested claims. Customize the subject focus here.

## Candidates (unapproved)

No standing authority. In CAPTURE/APPLY only, record a concise observation and
its source if worth reviewing; omit it when it has no useful next action.

## Adopted lessons

### Entry template
- Lesson:
- Gate: recurrence on two distinct occasions OR explicit user confirmation
- Evidence: source locators or confirmation
- Future action changed:
- Status: adopted | proposed policy change | retired
- Suggested change, if any: requires separate authorization before application

## Retired / consolidated

Keep short reasons or history locators. Consolidate before appending more lessons.
